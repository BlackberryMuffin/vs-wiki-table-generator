# Vintage Story Wiki Table Generator
This is a small project to automate the generation and formatting of certain tables for the [wiki](https://wiki.vintagestory.at) of the voxel based sandbox-survival game Vintage Story.


Note that these tables don't necessarily generate with all information, and some columns may have to be filled by hand.


To use this script, an installation of Vintage Story must be present, so that its assets can be accessed.

* The path to the desired installation must be specified as the `install_path` in `generate_all.generate(install_path)`.
